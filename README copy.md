Recoge datos de perfil de cliente: nombre, edad, ciudad.

Descripción de las carpetas:
Data: aloja los archivos .csv con los datos crudos (/raw) y procesados (/processed). A partir de esta información podemos sacar los análisis iniciales para empezar a desarrollar el estudio.
Notebooks: esta carpeta aloja archivos .ipynb donde se desarrollan los análisis de los archivos .csv. En estos notebooks se crean las tablas y gráficos que posteriormente ayudarán a sacar las conclusiones pertinentes.
SRC: esta carpeta aloja los archivos .py donde se hace la limpieza de datos extraidos de los archivos .csv crudos
